## 🌟 简介

DreamForge 是一款专注于 **dreamy / cinematic 梦幻风格** 的 AI 图像生成工具。

与其他 AI 工具追求写实风格不同，DreamForge 专门优化梦幻、电影感、艺术化风格，让每一次生成都充满想象力和美感。

### ✨ 核心特点

- 🎨 **梦幻风格专精** - 100% 优化 dreamy、cinematic 风格
- 🚀 **简单易用** - 输入提示词，秒生成图
- 💎 **用户友好** - 新用户免费试用积分
- 🔓 **开源项目** - 代码完全开源，可本地部署
- 🌐 **随时访问** - 无需安装，浏览器直接打开

## 🚀 快速开始

### 在线使用（推荐）

直接访问：https://dreamforge-679j.vercel.app

无需注册，打开即用。新用户有免费积分体验。

### 本地部署

```bash
# 1. 克隆仓库
git clone https://github.com/Dayangyang-Byte/dreamforge.git
cd dreamforge

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local，填入 API Key

# 4. 启动服务
npm run dev
```

**服务地址：**
- 前端：http://127.0.0.1:5177
- API：http://127.0.0.1:8787

## 📦 技术栈

- **前端**: Vite + React + TypeScript
- **后端**: Node.js + Express
- **部署**: Vercel (前端) + 自建服务器 (API)
- **模型**: 支持 GPTImage2 等多种模型
