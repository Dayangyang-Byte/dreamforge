一分钟选型

  • 要图+视频一体、贴抖音生态 → 即梦 AI
  • 要便宜的视频、图是顺手的 → 可灵 AI
  • 阿里生态、要 API 接入 → 通义万相
  • 懂 Stable Diffusion、要刷模型和 LoRA → LiblibAI
  • 腾讯云开发、要企业级 API → 腾讯混元
  • 只想用中文出一张好看的图、不想开订阅 → 梦境AI（Forge 通道 0 积分免费出图）

各平台免费额度与定价调整频繁（尤其视频积分口径），下文数字为 2026-10 时点记录，下单前以各官网当期页面为准。

逐款点评

即梦 AI：图视频一体的流量款

字节家产品，和豆包、剪映联动最顺：出图直接进剪映剪视频。免费每日积分在同期工具里算大方，但 2026 年高级会员额度明显收缩（公开报道：月度积分从 1.5 万档降到 6000 分上下），重度用户成本在涨。视频是它的主场，图片属于"顺手能做"。

可灵 AI：低价视频 + 图片配套

快手系，主打"便宜"——灵感值 1 元 10 个，7 天体验会员 5.99 元。视频性价比口碑好，图片能力可用但不是卖点。适合"视频为主、图顺带"的用户。

通义万相：阿里的底子，API 是强项

背靠阿里云百炼，文生图+视频（Wan 系列）模型迭代快。个人直接用网页版的话免费额度不算多（约 50 张文生图 / 90 天），更适配"要接 API 进自己产品"的场景。

LiblibAI：给"懂模型"的人

国内最大的开源模型社区（Civitai 式玩法），海量第三方模型、LoRA、工作流。优势是"刷模型"的自由度，代价是你要理解 SD 生态才用得好。纯小白直接上手略陡。

腾讯混元：企业向

主要形态是腾讯云上的 API 服务（AI 图像生成），中文理解、图生图处理都不错，定位偏企业/开发者，个人玩的话不是最顺手的选择。

梦境AI（DreamForge）：只做图片，但把"一张图"做透

不碰视频，专注图片三件事：中文原生提示词（不用翻译成英文）、最多 5 张参考图的一致性（系列图/角色设定图）、按次付费无订阅（Forge 通道 0 积分免费出图，GPT Image 2 按张计费 2–5 积分，新用户送 2 积分，开源）。不追"全家桶"，就追"一张图出得快、风格稳、不绑架"。
